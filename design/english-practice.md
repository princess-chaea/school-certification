# 영어 문장 연습실 설계 (과제 1 · 과제 3)

> 대상: 4~6학년 · 데이터: `data/english/*.json` · 상위 문서: `PLAN.md`

## 1. 과제 정의

| | 과제 1 · 오늘의 카툰 한 문장 | 과제 3 · 교과서 주요문장 |
|---|---|---|
| 문장 세트 | `task1-cartoon.json` (45문장, 4~6학년 공통) | `task3-grade4/5/6.json` (학년별 40문장) |
| 완료 기준 | 45개 중 **30개** 교사 확인 | **40개** 모두 교사 확인 |
| 한국어 해석 | 원본에 있음 | **AI 초안**(`koStatus: draft`). 영어 선생님이 검토한 뒤 승인 |
| 특이 사항 | 원문 오타 2건 수정(43번, 36번) | 단원마다 1칸(5·10·…·40번, 총 8칸)은 **학생이 단원 표현을 직접 입력** |
| 대체 표현 | — | `[afternoon, evening]`, `he/she`, `this[that]` 등은 `alternatives`로 모두 정답 처리 |

- 영어 인증에 필요한 과제 수(기본 2개)는 관리자 화면에서 설정한다.
- 금·은·동 단계는 **선택한 과제 전체 진행률**에 40/70/100%를 적용한다.

## 2. 문장 하나의 흐름

```
┌──────────────── 1회차 ────────────────┐
│ [1단계] 한국어 보고 영어 타이핑          │
│   "너 하나도 안 변했네."                 │
│   ┌──────────────────────────────┐      │
│   │ You haven't changed a bit.   │ [확인]│
│   └──────────────────────────────┘      │
│   ✔ 정답 → 정답 문장 공개 + 🔊 듣기        │
│   ✘ 오답 → 틀린 단어 표시, 다시 입력       │
│      2번 틀리면 [힌트] (첫 글자 Y_ h_ c_ a b_) │
│      3번 틀리면 [AI 설명] (왜 틀렸는지 한국어로) │
│                                          │
│ [2단계] 녹음하기                          │
│   🔊 원어민 발음 듣기 (브라우저 TTS)        │
│   🎙️ 녹음 → ▶ 내 녹음 듣기 → [저장]         │
│   (가능한 기기에서) 인식된 문장 보여주기    │
└──────────────────────────────────────────┘
        ● ○ ○  →  ● ● ○  →  ● ● ●
                         3회 완료 → [선생님께 검사 요청]
```

### 문장 상태 (`status`)
`new` → `practicing`(1~2회차) → `ready`(3회 완료) → `requested`(검사 대기) → `checked` ✅ / `retry`(다시 해 보기, 선생님 메모 포함) → 다시 `practicing`

- 한 회차가 완료되는 조건은 **타이핑 정답과 녹음 저장(1초 이상)**이다.
- `retry`를 받으면 회차 기록은 남기고, 1회만 더 하면 다시 검사를 요청할 수 있다. 3회를 다시 하지 않는다.
- 검사 요청은 문장 하나씩 하거나, 준비된 문장을 골라 한꺼번에 할 수 있다.

## 3. 타이핑 자동 채점 규칙

정답과 입력을 다음처럼 **정규화한 뒤 비교**한다.

1. 앞뒤 공백 제거, 연속 공백은 하나로, 대소문자 무시
2. 따옴표 통일: `’ ‘ ´` → `'`
3. 문장 끝 `. ! ?`와 쉼표는 무시. 문장 가운데 하이픈은 유지한다(`self-service`, `Jeju-do`).
4. 축약형은 같은 것으로 본다: `I'm=I am`, `can't=cannot=can not`, `haven't=have not`, `it's=it is`, `what's=what is`, `I'll=I will`, `I'd=I would`, `don't=do not`, `we're=we are`, `you're=you are`, `where's=where is`, `that's=that is`, `I've=I have` …
5. `alternatives`에 있는 문장도 모두 정답이다.

오답이면 **단어 단위로 비교**해서 빠진 단어, 틀린 단어, 남는 단어를 색으로 표시한다(LCS 비교, AI 비용 없음).

### 입력창 설정 (태블릿)
- `autocomplete="off" autocorrect="off" autocapitalize="off" spellcheck="false"`: 자동 수정이 답을 바꾸지 않도록
- **붙여넣기 금지**, 타이핑하는 동안 정답과 TTS는 숨김. 정답을 맞힌 뒤에만 공개한다.

### 학생 작성 칸 (과제 3의 5·10·15… 번)
- 학생이 `영어 문장`과 `뜻`을 직접 적는다. 칸 안내 문구는 "○단원에서 배운 표현을 골라 적어 보세요"이다.
- 그 뒤에는 다른 문장과 같이 3회 연습한다. 1단계 타이핑의 정답은 학생 본인이 적은 문장이다.
- 교사는 검사할 때 **표현이 단원에 맞는지도 함께 확인**한다. 대기열에서는 "학생 작성" 표시로 구분된다.

## 4. 녹음

- `MediaRecorder`로 녹음한다(webm/opus, 문장당 대략 50KB 이하). 녹음 시간은 최대 30초로 제한한다.
- Storage 경로는 `english/{uid}/{setId}/{no}.webm`이다. **문장마다 최신 녹음 1개만 덮어써서** 저장 공간을 아낀다(약 400명 × 70문장 ≈ 1.5GB).
- **발음 확인(선택)**: 브라우저 음성인식(`SpeechRecognition`, 무료)이 되는 기기에서는 인식된 문장과 일치하는 단어를 표시해 학생이 스스로 점검하게 한다. 통과 여부에는 반영하지 않는다. 판단은 교사가 한다.
  - 기기에 따라 녹음과 음성인식을 동시에 쓰지 못할 수 있다. 실제 학교 태블릿으로 확인한 뒤 켤지 정한다(질문 1).
- **원어민 발음 듣기**: 브라우저 `speechSynthesis`(en-US)를 쓴다. 비용이 없다.

## 5. 교사 검사 화면

```
영어 검사 대기열            [4학년 ▾] [1반 ▾]   대기 23건
┌─────────────────────────────────────────────────────┐
│ ☐ 4-1 김○○  과제3 #6  Are you happy?        ▶ ✔ ↺ │
│ ☐ 4-1 김○○  과제3 #10 (학생 작성) I like ...   ▶ ✔ ↺ │
│ ☐ 4-1 이○○  과제1 #3  I can't wait!          ▶ ✔ ↺ │
└─────────────────────────────────────────────────────┘
[선택 항목 모두 통과 ✔]   ▶ 3회차 녹음 재생  ✔ 통과  ↺ 다시(메모)
```

- 교실에서는 학생이 선생님 앞에서 직접 말하고 선생님이 ✔를 누르는 방식을 기본으로 한다. 녹음 재생은 나중에 몰아서 확인할 때 쓴다.
- ✔를 누르면 Firestore에 `checked`, `checkedBy`, `checkedAt`이 기록된다. 학생 화면은 실시간 구독 중이므로 **"띵동!" 효과음과 ✅ 도장 애니메이션**이 바로 뜬다. 효과음은 Web Audio로 만들어 별도 파일이 없다.
- **학생별 교사 확인서 출력**: 운영 계획서의 인증 기준에 "교사 확인서 탑재"가 있다. 공문 서식과 같은 표에 확인한 날짜와 확인 교사를 자동으로 채워 인쇄하거나 PDF로 저장한다.

## 6. 데이터 구조

```
sentenceSets/{setId}
  title, grades[], goal, items[{no, unit, type: fixed|student, en, ko, koStatus, alternatives[]}]

english/{uid}/items/{setId}_{no}
  setId, no
  custom: {en, ko}                 # type=student 칸일 때 학생 입력
  rounds: [{typedOk, attempts, audioPath, durationMs, sttText, at}]   # 최대 3개(+retry)
  status: new|practicing|ready|requested|checked|retry
  requestedAt, checkedBy, checkedAt, teacherNote

progress/{uid}.programs.english
  tasks: {task1: {checked: 12, goal: 30}, task3: {checked: 40, goal: 40}, task2: {...}, task4: {...}}
  selected: ["task1","task3"]      # 학생이 고른 과제
  percent, medal
```

- **보안 규칙**
  - 학생: 자기 `english/{uid}` 문서만 쓸 수 있다. `status`는 `checked`로 바꿀 수 없다.
  - 교사: 담당 학년·반만 `checked`/`retry`로 바꿀 수 있다.
- `progress`는 Cloud Function이 `checked` 변경을 감지해 다시 계산한다.

## 7. 관리자 화면 (문장 세트)

- 세트별 문장 표 편집(추가, 수정, 순서 변경), CSV·엑셀 붙여넣기 일괄 등록
- `koStatus`가 `draft`인 해석에는 "AI 초안" 표시를 하고, 영어 선생님이 검토 후 [승인]
- 과제별 목표 수(30·40)와 영어 인증에 필요한 과제 수(기본 2) 설정
- 다음 학년도에 다른 교과서를 쓰게 되면 세트를 복제해서 수정한다(지속 사용 고려)

## 9. 남은 확인 사항

1. **태블릿 기종**(갤럭시탭 / 크롬북 / 아이패드): 녹음과 음성인식 동시 사용 가능 여부가 기종마다 다르다.
2. **검사 교사**: 4~6학년 영어 검사를 **영어 전담 선생님**이 하는지, **담임**이 하는지, 둘 다인지에 따라 교사 권한이 달라진다.
3. **과제 3 해석 초안 검토**: 영어 선생님이 `data/english/task3-grade*.json`의 `ko`를 확인해야 한다. 관리자 화면이 생기면 그 화면에서 해도 된다.
